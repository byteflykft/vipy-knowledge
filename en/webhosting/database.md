# Managing Databases

## Creation

:::warning It is important to choose a long, secure password to protect your website. Allow remote access only when necessary.:::

1. Log in to your hosting control panel and click on **Databases** in the left-hand menu, then click **Add Database**.
2. Fill in the database name, username, and password fields.
3. For remote access, it is recommended to select **Allow local connections only** if you don’t plan to connect from elsewhere. If you need external access, you can allow specific IP addresses. **Allow connections from any host** should only be used for testing, not for regular use.
4. Click the **Save** button.

## Usage
- By displaying the connection details, you can see which information must be entered in your website or software.
- In the actions column, click the middle button to open **phpMyAdmin**, where you can manage your database contents.
